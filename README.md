# wikiflow-lakehouse

The [wikiflow](https://github.com/loadbearingcode-222/wikiflow) hourly Wikimedia pageviews
pipeline, rebuilt on Databricks: Lakeflow jobs and declarative pipelines, Delta tables,
Unity Catalog, and Asset Bundles deployed from git.

Work arrives as numbered stories, one pull request each, in the order listed in
[`docs/MILESTONES.md`](docs/MILESTONES.md). This README becomes the full tour in M5-S3.
